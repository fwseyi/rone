# Rone

A static fashion-commerce front-end for Rone, designed as a complete storefront prototype.

## Run locally

No install or build step is required. From the project directory, serve the site with any static server, for example:

```sh
npx serve .
```

Then open the address shown by the server. The homepage is `index.html`.

## Deploy to Vercel

Import the GitHub repository into Vercel and deploy it as an **Other** static site. No framework preset, build command, or environment variables are needed.

## Notes

This is a front-end prototype. Product data, bag, saved pieces, account, checkout, tracking, and currency preferences run in the browser; a production shop still needs a backend, authentication, inventory, payment processing, transactional email, and legally reviewed store policies.

Some editorial imagery is loaded from Pexels. Confirm that every final asset is appropriately licensed for commercial use before launch.
